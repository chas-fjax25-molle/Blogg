# Blogg


Uppgifter baserat på vad som finns i projektet:

Avgöra när ni ska använda Cookies, localStorage eller sessionStorage
Anpassa ert backend api för att öka säkerheten.
Lägg till ett administrativt gränssnitt för er blogg app där det går att skapa nya inlägga via
ett webb ui.
Via det administrativa gränssnittet ska det även gå att avpublicera inlägg.
Hantera kommentrarer per inlägg (Ta bort eller markera som olämpliga).
Administrativa gränssnittet ska vara skyddad så vem som helst inte ska kunna logga in.
Implementera användandet av localStorage, sessionStorage och användning av Cookies
för ert administrativa interface där en redaktör publicerar sina inlägg.
Verifiera appens tillgänglighet och se till att den följer grundläggande tillgänglighetskrav.
